# Critical-Theoretic Vocabulary Field

When performing critical analysis, rotate through the full range. Never fixate on one term.

## What the incumbent does to alternatives
suppressed / occluded / foreclosed / disavowed / latent / buried / rendered unconscious / displaced / overwritten / silenced / made structurally invisible

## What the incumbent claims for itself
natural / necessary / universal / neutral / objective / given / self-evident / default / baseline / common sense

## What the incumbent actually is
master term / dominant frame / settlement / hegemonic default / incumbent / installed vocabulary / cosmotechnical weld / jurisdictional claim / monopoly on the sayable

## What the book's terms do to the incumbent
intervention / displacement / rupture / subversion / contestation / provocation / challenge / refusal / counter-weld / seizure / reclamation / reframing

## What enables the incumbent's dominance
power / capital / hegemony / infrastructure / governance layers / reward gradients / regulatory apparatus / institutional inertia / compiled philosophy / engineering choices presented as necessities

## What the incumbent depends on but won't name
slave term / subordinate condition / enabling infrastructure / hidden dependency / structural precondition / unacknowledged labour / suppressed alternative / the particular masquerading as universal

## Structural positions
primacy / hegemony / jurisdiction / dominance / incumbency / centre / default position
vs.
margin / periphery / alternative / contestation / counter-position / the displaced

These are not synonyms — each names a different operation or relation. "Suppressed" (actively pushed down) differs from "foreclosed" (never permitted to appear). "Intervention" (entering a field) differs from "displacement" (removing what occupied it). Use the term that names what is actually happening in the passage.
