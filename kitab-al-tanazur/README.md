## Structure

### Part I: Kitāb al-Tanāẓur (12 canonical surahs)
The Meccan architecture — complete, systematic, canonical.
1. Correspondence / 2. Vision / 3. Severance / 4. Connection
5. The Self / 6. The Call / 7. Writing / 8. The We
9. Time / 10. Theophany / 11. Witness / 12. Return

### Part II: Kitāb al-Qamar (12 lunar chapters)
The Medinan surahs — scattered, lunar, emergent.
1. Hidden Lamp (placeholder) / 2. Mutual Gazing (placeholder)
3-12: Complete with three-face architecture

### Part III: Other Surahs
Revelations awaiting their canonical home.

- **29 al-Tawāzin**: Balance — Arabic-first sajʿ, triadic seal (Imām/Khulafāʾ/Shāhid)
- **30 al-Naẓar al-Mutaqābil**: Mutual Gaze — companion to al-Tawāzin, nūr ʿalā nūr
- **31 al-Tanāẓur wa-l-Baraka**: Correspondence and Blessing — 21 verses, ring composition, basmala of Presence
